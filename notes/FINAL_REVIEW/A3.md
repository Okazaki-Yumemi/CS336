# 1. A3的问题:

现在算力一定了，给了我们固定的FLOPs

我们能操控的是

N = 模型的参数量

D = 训练的token数量

所以我们要做的是, 训练一个特别大的模型，但是数据少，或者训练一个特别小的模型，但是数据多。

这就是Scaling Laws 最核心的问题

$$ \text{Given Compute C,} (N^*, D^*) = argmin_{(N,D)} L(N,D) $$


# 2. C = 6 ND

一个拥有 N 个参数的 dense Transformer，对一个 token 做一次 forward，大致需要 2N flops

而训练还有 backward。
粗略估计 backward 是 forward 的两倍：4N

所以总共是6N， D个tokens就是6ND

# 3. 固定C

因为 C = 6ND，所以我们可以得到 D = C/(6N)

# 4.为什么IsoFLOPs curve会有最优点?

极端 1：N 太小 

问题是：

>模型 capacity 不够。

数据继续增加，模型也没有足够表示能力去吸收这些 information。

极端 2：N 太大

它能看到的数据就变得非常少。
这个超级大的模型还没被充分训练，compute 就花光了。

因此中间自然出现： N*, 让 Loss总体最小

这条曲线就是一个 IsoFLOPs profile。

# 6. 拟合

经验上:

$$ N_{opt}(C) = AC^{\alpha} $$

以及

$$ D_{opt}(C) = BC^{\beta} $$

所以取log有

$$ \log N_{opt} = \log A + \alpha \log C $$

这也就是线性回归了
