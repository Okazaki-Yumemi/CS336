# Part5: Distributed Data Parallel

最简单想法：
每张卡复制完整模型：
```
GPU0:
model copy

GPU1:
model copy

GPU2:
model copy

GPU3:
model copy
```

每张处理不同 batch：
```
batch
 |
 +-- GPU0
 +-- GPU1
 +-- GPU2
 +-- GPU3
```

forward独立做，不过backward的时候，每张gpu得到的gradient是不一样的，需要同步

$$ g = frac{1}/{4} (g_0 + g_1 + g_2 + g_3) $$

这就是 All Reduce，所有GPU的gradient都要同步。

# Part 8: Fully Sharded Data Parallel

进一步：
三个都 shard：
Parameters
Gradients
Optimizer states

```
GPU0:

parameter shard 0
gradient shard 0
optimizer shard 0

parameter shard 1
gradient shard 1
optimizer shard 1
```

但是问题来了：forward 时：GPU0 需要完整 parameter。怎么办？

就是all-gather

forward前 all-gather出来全部权重，backward后扔掉
